# AGENTS.md

Instructions for AI assistants other than Claude Code (Codex, Cursor and others).

Follow `CLAUDE.md` in this folder: it describes the script, the read commands, and the rules for
anything posted under the member's name. If `CLAUDE.local.md` exists, read it for who the member
is and what they work on.

For common tasks, follow the step-by-step instructions in `.claude/skills/`:

- `whats-new/SKILL.md`: catch the member up on the group.
- `weekly-update/SKILL.md`: draft and post their weekly update.
- `new-project/SKILL.md`: add a project card.

The rules that matter most: never print or commit the login in `.env`; never message, comment or
post on anyone else's project; and show the member the exact text and wait for a clear yes
before anything is posted.
