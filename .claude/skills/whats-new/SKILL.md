# What's new

1. Run `node bin/hgt.mjs news --json`. If the member asks about a longer stretch, also run
   `node bin/hgt.mjs updates <count> --json`.
2. Read `CLAUDE.local.md` if it exists, to know who the member is and what they work on. If it
   doesn't exist, ask once what they work on, and offer to save the answer there.
3. Answer in this order, and leave out anything that isn't worth their time:
   - **For you:** needs the member could meet, work that overlaps theirs, people worth talking to.
     Quote what was posted, name the member and project, and suggest one concrete first step.
   - **New and changed projects:** one line each.
   - **Everything else:** a sentence or two at most.
4. Don't message, comment, click "I'm interested" or "I can help" for them. If they want to reach
   out, draft the message for them to send.

"New" means new since the last `news` run, because the site shows no dates on projects. Say so
the first time, when every project counts as new.
